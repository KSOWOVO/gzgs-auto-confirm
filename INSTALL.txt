================================================================
  网校自动确认  v1.0.1  ·  安装说明
================================================================

它干什么
--------
你的广工商网校看课时，视频播到一半会弹一个「学习验证」的框，
不点「确定」就一直停着，后面的自动连播也断了。

这个扩展会自动帮你点掉它，然后让视频继续播。
装一次，以后一直有效。


安装（4 步，约 1 分钟）
----------------------

本文件夹里有：
  extension\     ← 扩展本体
  INSTALL.txt    ← 你正在看的这个


【第 1 步】打开开发人员模式

  浏览器地址栏输入：  edge://extensions    然后回车

  找到页面【左下角】的「开发人员模式」，
  点一下，让灰色开关变成蓝色。


【第 2 步】点「加载解压缩的扩展」

  开关点亮后，【左上角】会多出三个按钮，
  点最左边那个蓝色的「加载解压缩的扩展」。


【第 3 步】选中 extension 文件夹

  弹出选择窗口，找到本文件夹里的 extension，
  选中它（是选中这个文件夹本身，不要双击点进去），
  再点右下角「选择文件夹」。


【第 4 步】完成

  列表里出现「网校自动确认」这张卡片，就装好了。
  回到网校页面按 F5 刷新。

  用 Chrome 的话：地址换成 chrome://extensions，
  但「开发者模式」开关在【右上角】，不在左下角。


怎么知道在正常工作
------------------
网校页面右下角会出现一个小绿标：

    ✓ 自动确认 0

看到它 = 跑起来了。
之后每次弹窗，1~4 秒内自动点掉，数字会 +1。

点一下绿标 = 临时暂停；再点一下 = 恢复。


不想用了怎么卸载
----------------
edge://extensions  →  找到「网校自动确认」→ 点「移除」

然后把本文件夹整个删掉就行。


安全吗
------
· 不联网、不上传任何数据
· 不读取你的账号密码、成绩、课表
· 只在 usc.gzgs.edu.cn 这个域名下生效
· 代码只有 3 个文件，四百行不到，谁都能看清楚


出问题怎么办
------------
1. 先确认 edge://extensions 里它是「已启用」状态
2. 在网校页面按 F12，切到 Console 标签
   能看到 [网校助手] 开头的日志，说明扩展跑起来了
3. 把报错截图发给分享给你的人
